# -PEGA-Ticket-and-Booking-System
The Ticket and Booking System is a Pega-based application designed to simplify and manage the complete ticket booking process. It allows users to search for available services, select tickets, provide booking details, and track their booking status. The system uses Pega case management and workflow automation to handle bookings efficiently.
# Movie Ticket Booking Management Application

This project is developed using Pega Platform.

## Case Type
Movie Ticket Request

## Stages
1. Request
2. Availability
3. Approval
4. Booking Execution

## Main Features
- Submit movie ticket request
- Check show availability
- Calculate booking cost
- Confirm booking
- Maintain Movie and Show data
- Process ticket booking
- Send booking confirmation
- Configure SLA
- Route booking based on show type

## Platform
Pega App Studio / Pega Infinity
